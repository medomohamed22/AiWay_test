## إصلاحات السلوك الحساسة

- إتمام الدفع يقفل سجل الدفعة ويستخدم snapshot اعتمادها، ويستدعي الشراء القديم مرة واحدة في معاملة. txid لا يمكن أن يضيف رصيدًا لدفعتين مختلفتين.
- انتهاء صلاحية quote أو تعديل الباقة بعد اعتمادها لا يمنع إنهاء دفعة موثقة مخزنة. دفعة غير محفوظة ما زالت تحتاج تحقق quote الموقع قبل الاسترجاع.
- إعادة فحص الدفع من الإدارة تستخدم نفس تحقق مالك Pi والمبلغ والباقة والتوكينات. نجاح HTTP وحده لا يكفي: حالة الإتمام ومعرّف المعاملة يجب أن يطابقا.
- تعديل رصيد الإدارة يستخدم قفل المستخدم وrequest_id وسجل مراجعة في معاملة واحدة. فشل سجل المراجعة يُرجع العملية المالية كلها.
- أخطاء قراءة ضوابط المستخدم والمميزات لا تفتح الخدمات. غياب جداول إعدادات legacy معروف فقط يحتفظ بالتوافق مع الافتراضات القديمة.
- قائمة أدوات أو باقات خالية نتيجة تعطيلها لا تعيد الافتراضات تلقائيًا.
- تكلفة صورة تُحسب مرة واحدة في الحساب ولوحة الإدارة، وتبقى بعد تنظيف سجل الملف. تسعير endpoints الذي يأتي كمصفوفة يظل محفوظًا.
- عند غياب تكلفة الصورة من OpenRouter وفشل lookup، تستخدم المحاسبة تقدير الصورة بدل حساب توكين نص واحد. تقدير بلا تكلفة موثوقة يحمل `pricingBasis: estimate`.
- مهلة طلب JSON تشمل قراءة الجسم، وأخطاء الخدمة تعرض رسائل محكومة. حد جسم الطلب يفحص الحجم الفعلي أيضًا.
- تم إصلاح استدعاء الدالة الناقصة `isTextChatModel` الذي كشفه ESLint.

## حدود التحقق

الفحوص المحلية تشمل 37 اختبارًا، منها اختبارات بث الشات وتنزيل الملفات، وعمل PostgreSQL المتزامن. الاختبارات تتعمد محاكاة تعطل الخدمات الخارجية بدل استهلاك مدفوعات أو رصيد حقيقي.

لم يتم النشر أو تغيير Supabase الحقيقي. لا توجد مفاتيح خدمات أو dump للقاعدة ضمن الملف الأصلي. لذلك لم يُتحقق من الدفع الحقيقي داخل Pi Browser، أو RLS الفعلي، أو سياسات Storage، أو تعريفات دوال حجز/انتهاء الرصيد في قاعدة الإنتاج. تعريفات الدوال القديمة لا يتم استبدالها؛ راجع preflight ثم smoke tests على staging.

توقيعات RPC ومخطط SQL التجريبي موثّقان في `tests/fixtures/legacy-schema.sql`. هذا الملف للاختبارات فقط.

التحسينات تحافظ على مسارات API القديمة وعلى نظام الباقات والتجربة والبث والمرفقات والمتابعة وتنزيلات الشات والصور والدعم والإدارة. لا يمثل هذا ضمانًا لكل إعداد في بيئة لم تتوفر للمراجعة.
