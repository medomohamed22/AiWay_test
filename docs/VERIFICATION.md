يمكن إعادة فحص الخادم محليًا في بيئة اختبار فقط عبر:

```sh
node --import ./tests/setup.mjs scripts/dev.mjs
# في terminal آخر:
node tests/smoke.mjs
```

`tests/setup.mjs` يستخدم قيمًا تجريبية، ولا يُستخدم لتشغيل بيئة الإنتاج.

لم تُختبر مفاتيح الخدمات الحقيقية أو قاعدة Supabase الأصلية أو عملية Pi مالية حقيقية. ملف fixture SQL للاختبارات يمثل عقد الدوال القديمة، ولا يستبدل مراجعة schema الفعلية واختبار staging.
